# Git et GitHub pour les projets d'équipe

*Contexte : BTS CIEL, projets menés en équipe dans l'organisation GitHub
`btsciel-toulon`, avec Git utilisé depuis VS Code.*

Trois documents, à lire **dans l'ordre**, du début à la fin :

| Document | Ce que vous y apprenez | Durée |
|---|---|---|
| [doc1 — Git, GitHub et création du compte](doc1-git-github-et-creation-du-compte.md) | Le principe du contrôle de version, ce que sont un commit, un push, un dépôt, une équipe, un Project. Création et sécurisation de votre compte GitHub, acceptation de l'invitation, configuration de Git | 30 min, une seule fois |
| [doc2 — Travailler en projet](doc2-travailler-en-projet.md) | Ce que prépare votre professeur (équipes, dépôt, tableau), le tableau Kanban, comment relier une tâche au code, aux schémas et aux cartes, comment terminer une tâche par un commit | 20 min |
| [doc3 — Git dans VS Code](doc3-git-dans-vscode.md) | Les gestes de tous les jours : cloner, indexer, valider, synchroniser, ne pas versionner n'importe quoi, résoudre un conflit | 20 min, puis aide-mémoire |

## Avant de commencer

- L'**adresse e-mail** que vous avez fournie à votre professeur, configurée sur
  votre **smartphone** : c'est elle qui sert à créer votre compte GitHub.
- Un poste de la salle avec **VS Code** et **Git**, ou votre ordinateur
  personnel.

## Ce que vous saurez faire à la fin

- Créer et sécuriser un compte GitHub, et rejoindre l'organisation du BTS.
- Récupérer le dépôt de votre équipe sur votre disque `U:`.
- Répartir le travail dans le tableau Kanban, et relier chaque tâche à ce que
  vous produisez.
- Enregistrer et partager votre travail depuis VS Code, en fermant vos tâches
  par vos commits.
