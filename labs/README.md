# Labs — tutoriels et travaux pratiques

Ce dossier regroupe les **supports pédagogiques** : tutoriels complets et sujets
de travaux pratiques, destinés aux étudiants.

Ce qui les distingue des procédures du dossier [`how-to`](../how-to/) : on ne
vient pas y chercher une commande, mais une **progression**. Un lab explique le
principe avant le geste, dit pourquoi les choses sont ainsi, montre ce qu'on
doit voir à chaque étape, et se termine par ce qu'il faut retenir. Il se lit en
entier, du début à la fin.

Chaque sous-dossier est autonome et contient son propre `README.md`.

## Sommaire

| Lab | Sujet |
|---|---|
| [`ssh-key`](ssh-key/) | Créer et utiliser sa clé SSH pour le développement à distance : principe de la paire de clés, mise en place sur un poste Windows en domaine, déclaration de la clé sur une carte Raspberry Pi |
| [`github`](github/) | Git et GitHub pour les projets d'équipe : principe du contrôle de version, création du compte, organisation d'un projet (équipe, dépôt, tableau Kanban), Git dans VS Code |
